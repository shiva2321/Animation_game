# QUICK REFERENCE - 3D PARTICLE COLLISION GENERATOR

## START THE APP
```bash
python main.py
```

## BUTTONS

| Button | Purpose |
|--------|---------|
| **Play** | Start animation |
| **Pause** | Pause/Resume animation |
| **Apply New Settings** | Reset with current settings (NEW!) |
| **Reset** | Clear everything |

## SETTINGS (LEFT PANEL)

- **Boundary Type**: Circle / Square / Triangle
- **Object Shape**: sphere / cube / star / triangle
- **Color Scheme**: 5 different themes
- **Max Objects**: 5-200 (particle flow limit)
- **Object Size**: Min-Max radius
- **Initial Speed**: Min-Max velocity
- **Audio Controls**: Master / Collision / Bounce volumes

## NEW FEATURES

### 3D Effects ✨
- Shadows under particles
- Bright highlights for shine
- Rotating rings for depth
- Glowing boundary
- Proper depth rendering

### Apply New Settings 🔄
- Green button in controls
- Restart animation instantly
- Apply all current settings
- Keep animation running
- No pause!

### Continuous Animation ♾️
- Infinite particle spawning
- Particles flow around max limit
- Never stops generating
- Always mesmerizing
- Smooth transitions

## HOW TO USE

1. **Adjust settings** (left panel)
2. **Click Play** to start
3. **Watch particles bounce** and collide
4. **Change settings** anytime
5. **Click "Apply New Settings"** to restart
6. **No need to click Play again!**

## EXAMPLE: Try Different Shapes

1. Max Objects: 150, Speed: 7/10

3. Change Shape to cube
4. Click "Apply New Settings"
5. Change Shape to star
6. Click "Apply New Settings"
7. Change Shape to triangle
8. Click "Apply New Settings"

Watch how each shape behaves differently!

## TROUBLESHOOTING

| Problem | Solution |
|---------|----------|
| Nothing appears | Check if Play button shows Pause (running) |
| Slow performance | Reduce Max Objects to 50-100 |
| Can't see particles | Make sure Play is active |
| Want new animation | Click "Apply New Settings" |
| Want total reset | Click "Reset" then "Play" |

## ADVANCED SETTINGS (RIGHT PANEL)

- **Reflections**: Toggle reflection effect
- **Gloss Effect**: Toggle shine effect
- **Save as Preset**: Save configuration
- **Reset to Default**: Restore defaults
