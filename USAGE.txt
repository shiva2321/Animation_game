3D PARTICLE COLLISION GENERATOR
================================

QUICK START
-----------

1. Open Command Prompt in this folder
2. Run: python main.py
3. Click "Play" to start the simulation
4. Enjoy!


FEATURES
--------

✓ 2 objects start bouncing
✓ Each collision creates a new object
✓ Speed increases over time
✓ Bounces and collisions play musical tones
✓ Beautiful 3D visuals (spheres, cubes, stars, triangles)
✓ Multiple boundary types (circle, square, triangle)
✓ 5 color themes to choose from
✓ Full interactive dashboard with controls
✓ Preset management (save/load your favorites)
✓ 60 FPS smooth rendering


CONTROLS
--------

LEFT PANEL (Settings):
- Boundary Type: Choose circle, square, or triangle
- Object Shape: Choose sphere, cube, star, or triangle
- Color Scheme: Pick from 5 themes
- Max Objects: Set how many objects can spawn (5-200)
- Object Size: Min/max size range
- Initial Speed: Min/max velocity range
- Audio Controls: Volume for collision and bounce sounds
- Mute: Turn off all sounds

CENTER PANEL (Preview):
- Play: Start the simulation
- Pause: Pause the simulation
- Reset: Clear and restart
- Speed Slider: Adjust simulation speed (1-10)

RIGHT PANEL (Advanced):
- 3D Shadows: Toggle shadow effects
- Reflections: Toggle reflection effects
- Gloss Effect: Toggle shiny highlights
- Info: Shows how the app works
- Save Preset: Save your current configuration
- Reset to Default: Restore default settings

STATUS BAR:
- Shows current object count / max objects
- Shows current FPS (frames per second)


HOW IT WORKS
------------

1. PHYSICS SIMULATION:
   - 2 objects start bouncing inside a boundary
   - They collide elastically (like real balls)
   - Each collision creates 1 new object
   - Objects keep bouncing until max reached
   - Speed increases 10% per frame (faster over time)
   - Gravity pulls objects slightly downward

2. AUDIO SYSTEM:
   - Collision: Plays a musical note (pentatonic scale)
   - Bounce: Plays a percussion sound
   - All tones generated in real-time
   - No audio files needed!

3. VISUAL EFFECTS:
   - Realistic 3D-looking 2D graphics
   - Shadows show depth
   - Highlights show shininess
   - Motion trails show velocity
   - Collision pulses show impacts
   - Glowing boundary

4. COLOR SCHEMES:
   - Pastel Dreams: Soft, calming colors
   - Ocean Breeze: Cool teals and blues
   - Sunset Glow: Warm oranges and pinks
   - Forest Magic: Natural greens and browns
   - Neon Nights: Bright energetic colors

TROUBLESHOOTING
---------------

Q: Nothing happens when I click Play
A: Wait a few seconds, objects need to collide to spawn new ones

Q: Can't hear any sound
A: Check the volume sliders on the left panel
   Make sure "Mute" is not checked

Q: Application is slow
A: Reduce "Max Objects" setting
   Disable visual effects on the right panel

Q: Application won't start
A: Ensure dependencies are installed:
   pip install -r requirements.txt
